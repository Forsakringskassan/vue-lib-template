# Component Library Developer Guides

Documentation for creating and maintaining component libraries using the `@forsakringskassan/vue-lib-template`.

## Guide Index

| Guide                     | Purpose                                                                 | Link                                                               |
| :------------------------ | :---------------------------------------------------------------------- | :----------------------------------------------------------------- |
| **Getting Started**       | Project scaffolding with Cloneman, installation, and project structure. | [GUIDE_GETTING_STARTED.md](./GUIDE_GETTING_STARTED.md)             |
| **Developing Components** | Architecture (Types, Logic, UI), create-flow, and styling.              | [GUIDE_DEVELOPING_COMPONENTS.md](./GUIDE_DEVELOPING_COMPONENTS.md) |
| **Testing & Quality**     | Unit testing with Vitest, UI testing with Cypress, and Linting.         | [GUIDE_TESTING_AND_QUALITY.md](./GUIDE_TESTING_AND_QUALITY.md)     |

| **Toolchain Cheat Sheet** | Quick reference for all `npm` scripts and the build pipeline.           | [GUIDE_TOOLCHAIN.md](./GUIDE_TOOLCHAIN.md)                         |

## Recommended Workflow

Suggested order for new contributors:

1. **Getting Started** $\rightarrow$ Set up your environment.
2. **Developing Components** $\rightarrow$ Build your first feature.
3. **Testing & Quality** $\rightarrow$ Ensure it works and stays clean.
4. **Documentation** $\rightarrow$ Make it discoverable for others.
5. **Toolchain** $\rightarrow$ Use this as a reference for daily commands.
